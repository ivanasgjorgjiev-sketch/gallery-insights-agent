# Milestone 10 decisions: Manager Experience

_Approved by the product owner on 2026-10-27 (decisions D1–D7 with refinements). Presentation-layer changes
only: the agentic analysis, deterministic tools, thresholds, publication gate, grounding and safety checks, source
data, the five protected source documents, the 28 locked guided answers, the demo recording and the evaluation
history are unchanged. No M10 content makes an Anthropic call._

## Goal

Make the Gallery Insights Agent feel like a product a Gallery Operations Manager would use: a short briefing of
what happened, each insight tied to a recognisable (fictional) artwork, plain-language evidence wording, and one
suggested follow-up per insight that the manager decides on.

## Decisions

| # | Decision |
|---|---|
| D1 | **Suggested follow-up**, one per published insight, under the heading "Suggested follow-up · No action taken automatically". **Refined 2026-10-28: rule-based and evidence-driven** (`gia/actions.py` `RULES`). A rule is chosen only from validated, tool-derived fields: pattern category, evidence strength (which must equal the published rating), which supporting measures qualified, rose too little, did not rise or are missing, and which screening criteria failed. Artwork IDs, titles and artist names never select a rule, so the same evidence gives the same suggestion for any artwork. Rules: sustained + well supported (two or more measures support it) → monitor whether it continues; sustained + partly supported (one measure) → cautious monitoring, describing each other measure as it is (a small rise gives "limited additional support", no rise "did not increase", a blank value "not recorded"); temporary spike → revisit only if it recurs; recent increase without a later day → worth monitoring, but not yet enough processed data to tell whether it will continue; rise from zero → treat as context; weak signal or not enough data → *no specific suggestion*, with the failed criterion or missing measure named. Any other combination gets the neutral "The available evidence does not support a specific follow-up suggestion." (never a generic suggestion); inconsistent evidence or a failed check is *unavailable* (fail closed). Metric names come from the pattern; no figure or date is stated. A1 and B1 keep the owner's approved wording; A2 and the recent-increase wording follow the owner's refinements of 2026-10-28. It says what the manager might do, not what to check in the data (guided Q4), and does not repeat the agent's own next step. |
| D2 | **Plain-language labels:** Well supported / Partly supported / For awareness only for higher-confidence / moderate-confidence / qualified; One-day spike, Steady, Rose from zero (small numbers), etc. for the classifications; "Supports it", "Weak", "Missing" on the tiles, matching the locked Q3 answer ("Supports it / Weak or missing / Against it"), with a legend. The technical rating and classification stay in the badge tooltip and the evidence summary; classifications and rules are unchanged; no wording implies a probability. |
| D3 | **Card heading** is the fictional catalog title with a thumbnail, artist, medium, "Fictional sample artwork" and the source label and ID ("source: Artwork A1 (A001)"). The agent's validated headline follows without its leading "Artwork A1: " prefix; nothing else in it changes. |
| D4 | **Fictional catalog** (`gia/catalog.py`): six titles, three artists and media, keyed by the existing IDs. Display only: never given to the agent, tools, checks or evaluations. Titles contain no digits, so they are never read as figures. |
| D5 | **Thumbnails:** abstract SVGs generated by `scripts/make_artwork_thumbnails.py` (one motif and palette per artist, layout seeded by the artwork ID) and committed in `assets/artworks/`. They are read from the repository by path, embedded as an `<img>` with alt text (works the same on Streamlit Cloud, no external hosting), with a neutral placeholder if a file is missing. No real artwork images. |
| D6 | **Daily briefing** (`gia/briefing.py`) replaces the one-line overview: the period, count chips, one checked sentence per published insight (strongest evidence first), and separate lines for artworks not prioritised, reportable patterns not published and drafts withheld by validation. The ordering explanation is in its help text. A sentence that fails its checks is left out; if the briefing cannot be built, the previous overview is shown. |
| D7 | Nine existing app and presentation assertions were updated for the intentional wording only (tile labels, card headings, catalog titles in the feedback and completion messages, and the briefing in place of the overview heading). No analytical or behavioural assertion changed. |

## Wording notes

- The briefing says "fell back to 31 on Oct 17", not "by Oct 17": the grounding check ties a figure to a date only
  with "on"/"for", and the wording was changed rather than the checker.
- Counts in the briefing are written as words ("Two sustained increases"), because every digit in checked text must
  be a verified figure.
